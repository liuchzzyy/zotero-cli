# 思维链结构设计：三级论证树＋推理桥

思维链、证据链和审查链是三种记录，不是三级树的三个层级。单篇笔记按思维链组织，并在相应节点和支持链旁展示证据与审查。本文件只定义思维链。

**思维链由“三级论证树＋推理桥”组成。**

三级论证树呈现论文的核心论点、分论点和论证理由；推理桥解释相邻层级之间的支持关系。**只有论证节点参与层级划分，推理桥不增加层级。**

思维链只整理作者的公开论证，不负责评价其证据是否充分或论证是否成立。独立的前提审查、异议、竞争解释和外推评议留给审查链。作者原文已经包含的条件、限定和语气仍需保留，以免改变原意；这不等于在思维链中新增审查内容。

---

# 一、名称、定义与职责

## 1.1 思维链的定义

> **思维链：根据论文公开文本，整理核心论点、分论点及其论证理由，并明确这些命题之间的支持关系和推理联系。**

它回答：

- 作者最想让读者接受什么？
- 作者从哪些不同方向展开论证？
- 每个方向具体依靠什么理由展开？
- 作者如何将下位命题连接到上位命题？

它不是作者真实思考过程的还原，也不是对论文结论正确性的认证。

## 1.2 结构术语

| 组成 | 规范名称 | 职责 |
|---|---|---|
| 第一级，主干 | **核心论点** | 整篇论文最主要的主张是什么 |
| 第二级，枝干 | **分论点** | 作者从哪些不同方向支持核心论点 |
| 第三级，树叶 | **论证理由** | 每个分论点具体依靠哪些下位命题展开 |
| 节点之间的联系 | **支持关系** | 哪个下位命题被作者用来支持哪个上位命题 |
| 对联系的解释 | **推理桥** | 为什么下位命题被作者用于支持上位命题 |

这里需要区分：

- **论证角度**是对分论点的分类标签，例如“副反应抑制”。
- **分论点**必须是完整命题，例如“界面层 X 降低了持续副反应的倾向”。

因此，**“论证角度”不能代替“分论点”本身**。

## 1.3 内容边界

思维链包含：

- 作者提出的论证命题；
- 作者组织这些命题的支持关系；
- 对公开论证联系的忠实重构；
- 作者原文中的必要条件、对象范围和表述强弱；
- 用于回指原文的文本定位。

思维链不包含：

- 实验结果、具体数值和文献支撑的证据卡片；
- 证据强度或充分性评价；
- 分析者新增的隐含前提审查、异议、竞争解释或适用范围评议；
- 对论文主张作出的“成立、不成立、支持不足”等审查裁决。

文本定位只用于确认“论文在哪里这样论述”，不作为证据链的替代。

# 二、第一级：核心论点

## 2.1 定义

**核心论点是作者希望通过整篇论文，使读者接受的最主要命题。**

它应当代表论文的中心贡献，而不只是研究对象、研究任务或结果清单。

例如：

- “研究 Zn 负极界面”——研究主题，不是核心论点。
- “制备了一种界面层”——完成的工作，不一定是核心论点。
- “界面层 X 对给定条件下 Zn 负极循环稳定性的改善具有实质作用”——可以作为核心论点。

核心论点可以属于机制解释、方法有效性、现象发现或理论判断，不必全部写成因果命题。

## 2.2 数量与选择规则

**通常一个，最多三个。** 这是为了控制展示结构，不是关于论文本身的普遍规律。

如果论文确实存在多个不能互相归入的中心贡献，可以并列保留；不要为了只留一个而拼成冗长的复合句。

识别时结合以下判断：

1. **贡献代表性**：它是否代表论文主要贡献，而非背景或附带发现？
2. **全文贯穿性**：主要讨论是否围绕它组织？
3. **文本定位**：摘要、引言末段、讨论和结论是否反复指向它？
4. **删除检验**：删去这项主张，论文的中心贡献是否发生实质变化？

删除检验只帮助识别中心地位，不判断命题是否正确。某个前提虽然不可删除，也不意味着它就是核心论点。

## 2.3 表述规范

每个核心论点至少说清：

> **针对什么对象，在什么范围内，作者主张什么。**

需要保留原文的强弱程度：

- “可能参与”不能改成“决定”；
- “与……一致”不能改成“证明……”；
- “在所测条件下有效”不能改成“普遍适用”。

这里是在忠实记录作者的命题，不是分析者重新裁定其强弱。

核心论点应尽量只表达一个中心判断。若句子中包含可分别成立或不成立的多个判断，应考虑拆分，或将其中一部分降为分论点。

## 2.4 应记录的信息

| 内容 | 含义 |
|---|---|
| 节点 ID | 稳定标识，规则见第七节；不使用层级位置代替身份 |
| 核心论点 | 一句完整命题 |
| 论点性质 | 描述、比较、机制、因果、方法有效性或推广性判断 |
| 原文限定 | 作者已表明的对象、条件和范围；未表明时不自行补入 |
| 表述归属 | 作者明示或文本重构 |
| 提取状态 | 明确或可重构；无法形成可靠命题的内容暂不作为正式节点 |
| 文本定位 | 对应的摘要、章节或段落 |
| 下属分论点 | 哪些方向被作者用来支持它 |

**这一层不放实验名称、具体数据或文献列表。**

# 三、第二级：分论点

## 3.1 定义

**分论点是围绕某个核心论点，承担一种可区分论证任务的下位命题。**

它不能只是与主题有关，而必须能够说明：

> 作者为什么将这个分论点作为核心论点的一项理由？

如果原文联系不明确，且不能根据公开文本可靠重构，应将该候选连接的提取状态记为“未明确”，显示为“联系未明确”，而不是强行补成支持关系。节点本身可以明确，但节点之间的联系仍未明确；两者分别记录。这是提取状态，不是对论证有效性的裁决。

## 3.2 “不同角度”的准确含义

不同角度指的是**承担不同的论证任务**，而不是采用不同的实验方法，或出现在不同章节。

例如，对于一个关于循环稳定性的核心论点：

- “降低持续副反应”；
- “缓和局部沉积集中”。

两者可能承担不同的解释任务，可以分别作为枝干。

但是：

- “用 XPS 研究界面”；
- “用 XAS 研究界面”。

这是方法不同，不能仅凭这一点划成不同分论点。

同样，**不同角度不等于独立论证**。分论点之间可能存在依赖，也可能被作者联合使用。思维链记录这种组织方式，不评价它们是否具有证据独立性。

## 3.3 与子标题的关系

**子标题是发现分论点的入口，不是分论点的最终边界。**

处理原则：

- 一个子标题只讨论一个论证任务，可以形成一个分论点。
- 同一个论证任务分散在多个章节，应合并整理。
- 一个章节同时承担不同论证任务，可以拆开。
- 仅介绍样品制备或测试过程的章节，不必自动形成分论点。
- “Results and discussion”这类宽泛标题，不能直接作为论证角度。

因此，分论点的组织依据是**论证功能**，不是文章目录。

## 3.4 合并与拆分规则

### 应当合并

不同表述实质上针对同一对象、同一判断和相近范围，承担相同论证任务。

合并后不会丢失重要的逻辑差别。

### 应当拆分

两个判断可以分别成立或不成立，或者它们支持上位论点的方式不同。

例如，“副反应减少”和“沉积更均匀”不能仅因为都与界面有关，就合并成“界面得到改善”。

### 不应强行处理

两个分论点存在部分交叉，但并不等价时，可以保留，并明确交叉关系。不能为了形成整齐的树而假装互斥。

### 单命题路径与换述

当核心论点下某条路径只有一个可提取命题，或分论点与论证理由难以区分时，以“是否承担可区分的论证任务”为准，而不是按句子长短或内容具体程度分类：

- 该命题承担一个可区分的论证任务，就作为第二级分论点；没有可分离的下位理由时注明“未进一步展开”，不额外生成第三级。
- 另一种表达只是同一命题的换述，就并入同一节点，保留必要的文本定位，不另立分论点或论证理由。
- 只有作者确实用一个不同的下位命题展开该分论点时，才设置第三级论证理由。

## 3.5 应记录的信息

| 内容 | 含义 |
|---|---|
| 节点 ID | 稳定标识，规则见第七节；重排或调整层级不自动换 ID |
| 论证角度 | 简短分类标签，便于浏览 |
| 分论点 | 完整、可判断的命题 |
| 上属核心论点 | 它服务于哪个中心判断 |
| 下属论证理由 | 作者如何进一步展开这个分论点 |
| 原文限定 | 作者已给出的对象和条件 |
| 表述归属 | 作者明示或文本重构 |
| 提取状态 | 明确或可重构；与上位节点的连接状态另记 |
| 文本定位 | 对应的章节或段落 |

**不规定分论点必须有多少个。** 数量应由论文实际包含的论证任务决定。

# 四、第三级：论证理由

## 4.1 定义

**论证理由是作者用于展开某个分论点的、更具体的下位命题。**

它在整个结构中处于中间位置：

- 相对于上层分论点，它提供理由；
- 它自身仍然是一个命题，而不是已经核实的事实。

例如：

- 分论点：界面层 X 降低了持续副反应的倾向。
- 论证理由：界面层 X 降低了可参与副反应的水在反应位点处的有效可达性。

这里整理的是作者提出的解释路径，**并不意味着已经确认这一解释正确**。

## 4.2 与其他内容的区别

| 内容 | 是否适合作为论证理由 |
|---|---|
| 一个具体的机制命题 | 可以，前提是原文确实包含该论证 |
| 对方法为何适用的解释命题 | 可以，取决于上层分论点 |
| “进行了 XAS 测试” | 不可以，只是研究动作 |
| “见 Figure 3” | 不可以，只是定位信息 |
| 某个数据值或实验结果清单 | 不在这里展开，属于证据链的内容 |
| “进一步证明了上述结论” | 不可以，没有提供实际理由 |
| 分论点换一种措辞 | 不可以，只是重复 |
| 分析者凭常识补出的机制 | 不可以冒充作者的论证理由 |
| 对作者解释新增的质疑或竞争解释 | 不属于思维链，留给审查链 |

这一层不要求固定“五个方面”。**先让理由忠实于论文，再考虑是否存在可复用的分类。**

## 4.3 深度规则

三级指的是**最多三级**，不是每条路径必须凑满三级。

- 原文没有继续展开，可以停在分论点。
- 原文只给出笼统解释，应如实记录“未进一步展开”，不补造理由。
- 原文包含更长的推导链时，按 5.3 的中间命题规则重新组织已有三级，不新增第四级，也不把关键中间命题隐藏在加长的推理桥中。
- 如果尚不能在三级内忠实表达，保留原文定位并注明“层级待整理；当前结构未完整表达原文路径”。这是展示整理状态，不是新增提取状态枚举，也不宣称原文关系未明确。

这些标记仅描述原文提取与展示的展开程度，不等于“作者论证有缺陷”。

## 4.4 应记录的信息

| 内容 | 含义 |
|---|---|
| 节点 ID | 稳定标识，规则见第七节；复用时引用同一 ID |
| 论证理由 | 一个更具体的完整命题 |
| 上属分论点 | 它用于展开哪个分论点 |
| 原文限定 | 作者对该命题已给出的条件和范围 |
| 表述归属 | 作者明示或文本重构 |
| 提取状态 | 明确或可重构；与上位节点的连接状态另记 |
| 文本定位 | 对应的章节或段落 |
| 复用关系 | 是否同时服务于其他分论点 |

# 五、支持关系与推理桥

## 5.1 支持关系是什么？

支持关系表示：

> **作者将下位命题作为接受上位命题的一项理由。**

基本方向是：

- 论证理由 → 分论点；
- 分论点 → 核心论点。

这里的“支持”记录的是作者的论证组织，不表示系统已经认定：

- 下位命题是上位命题的充分条件；
- 上位命题已经得到证明；
- 这条关系具有因果性质。

如果两个命题只是相关、并列或属于同一主题，不能仅凭主题相近就把它们整理为支持关系。

## 5.2 推理桥是什么？

**推理桥是对一条支持关系的简明解释，是该边的 `bridge` 属性，不是额外节点，也不单独分配节点 ID。**

它回答：

> 在作者的论证中，下位命题为什么被用于支持上位命题？

建议表达包含三个要素：

1. **连接对象**：下位命题与上位命题的哪个部分相关；
2. **连接方式**：作者通过什么逻辑或解释将它们联系起来；
3. **原文限定**：原文对这条联系已经给出的条件和表述强弱。

例如：

> 作者以持续副反应属于循环失稳过程这一联系，将副反应倾向降低作为给定条件下循环稳定性改善的一条解释路径。

这句话重述作者的公开论证路径，不额外断言该路径已经成立，也不自行添加其他机制或审查意见。

## 5.3 推理桥的表述约束

- 不能只写“因此支持核心论点”。
- 不能加入原文及其可定位论证中没有的科学事实。
- 不能将作者的“相容”改写成“唯一解释”。
- 不能将多步机制压成原文没有声称的直接因果关系。
- 不能把重构后的联系标成作者明确写出的原话。
- 不能在推理桥中新增质疑、竞争解释、支持强度或有效性裁决。

### 中间命题的三级内归位规则

先区分两类内容：推理桥可以说明作者如何把两个命题联系起来，但不能承载本应单独表达的、关于研究对象的新中间命题。不是任何连接说明都需要再拆成节点；判断标准是原文是否确实提出了一个不同于两端、承担独立论证作用的命题。

推理桥中发现这类中间命题后，只能在现有三级内归位：

1. **归入第三级**：只有它确实用于支持某个分论点时，才作为该分论点下的论证理由；合适的现有节点应复用，不重复建立。
2. **归入第二级**：只有它承担可区分的论证任务时，才作为分论点，与其他承担不同任务的分论点同层展示；必要时同步重新安排受影响节点。
3. **重新判断层级**：两种安排都不合适时，重新判断原有分论点、理由及其连接，不能新增第四级，也不能靠把推理桥写长来掩盖层级问题。

**归位不得颠倒原文支持方向，也不得把串联依赖误写为两个互不依赖的并列角度。** 例如，原文若是“原命题 B → 中间命题 M → 核心论点 C”，不能为了保留原有 B 的位置，把 M 放成支持 B 的树叶。若 M 符合分论点定义，可以将 M 整理为第二级，并将 B 重新归为其下的第三级理由；若不符合，就重新整理该路径，不强行保留原先的层级分配。

这里的“升为第二级”指展示归类，不代表 M 与原有分论点在逻辑上自动独立。调整后仍需分别说明实际支持关系。无法忠实归位时，明确标记展示未完整表达，不伪装成完整三级链。

若某项内容只是分析者认为这条联系必须依赖的额外前提，留给审查链，不补入思维链。

## 5.4 每条连接应记录的信息

| 内容 | 要求 |
|---|---|
| 边 ID | 每条支持关系的稳定标识；不以箭头文字或端点拼接代替 |
| 起点与终点 | 明确下位命题和上位命题 |
| 推理桥 | 作为该边的 bridge 属性，具体说明作者怎样建立支持联系 |
| 表述归属 | 作者明示或文本重构；联系未明确时不强行赋值 |
| 文本定位 | 能回指这条联系所依据的原文 |
| 目标部分 | 支持上位命题的哪个部分；不评价支持是否充分 |
| 组合方式 | 单独提供理由，还是与其他命题联合使用 |
| 提取状态 | 明确、可重构或未明确；后者显示为“联系未明确” |

其中，**“单独提供理由”不等于“单独足以证明”**。

联合支持不增加第四层，只需说明作者将哪些命题一起使用。若原文组织方式不能确定，应记为“未明确”，而不是自行替作者补全。此时推理桥不补写，候选连接也不计作已建立的支持关系；两端节点仍可各自保留。

# 六、共同遵守的表述规则

## 6.1 表述归属与提取状态分别记录

两个维度回答不同问题：

- **表述归属**：该命题或关系是作者直接说出的，还是根据公开文本整理重构的？
- **提取状态**：本次输入能否直接定位或可靠重构该命题或关系？

概念上分别记录，取值组合受一致性约束；并不是两个维度的所有组合都有效。两者都不表示命题真假、证据充分性或论证有效性，也不是概率或可靠性评分。

### 表述归属：只使用两个分类

#### 作者明示

论文明确提出的命题或关系。

允许压缩措辞，但不能改变原意、强弱和范围。

#### 文本重构

根据论文中分散的表达，整理出一个未被作者集中写成一句话的命题或关系。

必须能回指相关文本，不允许新增科学事实、另造机制或补齐作者没有给出的论证。

**思维链不设置“分析者提出”的论证节点。** 分析者新增的批评性判断留给审查链，不混入作者的支持结构。

### 提取状态：只使用三个分类

| 提取状态 | 定义 | 处理方式 |
|---|---|---|
| **明确** | 命题或关系已由作者直接表达，并有可定位的文本 | 保留作者语气与限定，记录文本定位 |
| **可重构** | 原文未集中直接表达，但可依据可定位的文本，在不新增事实或前提的情况下可靠整理 | 给出忠实重构的表述及其文本定位 |
| **未明确** | 现有输入不足以直接定位或可靠重构该命题或关系 | 不补造；关系显示为“联系未明确”，不建立正式支持连接 |

### 允许的组合与空缺规则

| 表述归属 | 提取状态 | 含义 |
|---|---|---|
| 作者明示 | 明确 | 作者直接表达，已定位 |
| 文本重构 | 可重构 | 根据原文重构，已记录依据 |
| null | 未明确 | 表述归属字段没有值；null 不是第三种归属分类 |

不使用“作者明示＋可重构”或“文本重构＋明确”等混搭。如果节点是作者明示，但它与另一节点的联系需要重构，应分别记录：节点为“作者明示＋明确”，连接为“文本重构＋可重构”。

attribution 的分类值只有“作者明示／文本重构”；未确定时保存 null，不把“暂不赋值”“留空”当作新的分类字符串。extraction_status 的分类值只有“明确／可重构／未明确”。二者分别存放。

节点与连接独立记录上述字段。正式论证节点应为“明确”或“可重构”；尚不能形成可靠命题的内容只作候选记录，不进入正式三级树。连接为“未明确”时，不影响两端节点已有的表述归属和提取状态。

## 6.2 区分命题与事实状态

树中的节点表示“论文提出了什么”，不表示“系统已经确认什么”。

因此：

- “作者提出 X 导致 Y”；
- “X 导致 Y 已被证实”；

是不同陈述，不能互换。

## 6.3 保留原文必要限定

原文中的对象、状态、条件和限定语应靠近所约束的命题。

这属于忠实表述，而不是审查。原文没有给出的限制，不由思维链自行补入；是否需要新增限定，留给审查链讨论。

## 6.4 不追求形式对称

不同核心论点可以有不同数量的分论点；不同分论点可以有不同深度。结构忠实比整齐重要。

## 6.5 允许复用，不重复计作新论点

一个论证理由如果确实服务于多个分论点，可以标明“同时支持另一分论点”，而不是复制成多个看似不同的理由。

因此，**树是主要展示形式，不意味着论文所有逻辑联系都天然是严格树状的。**

## 6.6 提取状态、展开程度与审查裁决分开

提取状态固定为“明确／可重构／未明确”。“未进一步展开”描述该分论点下没有可分离的下位理由，“本展示未继续展开”或“层级待整理”描述展示整理情况，均不作为提取状态的新取值。

一个分论点完全可以同时具有“作者明示＋明确”的记录，并注明“未进一步展开”。这些记录不能自动改写成“论证无效”“支持不足”或“存在逻辑缺陷”。后者属于审查链的判断，不是思维链的输出。

# 七、与平行模块的接口

本节只定义思维链交付什么、其他模块能够引用什么，不定义证据链或审查链的内部结构。

## 7.1 输出范围与版本

思维链记录包含：**文档标识、节点表、支持链表和文本定位信息**。文档标识记录 `library_ref`（Zotero 库类型及库 ID）、`parent_item_key`（父条目 key）、`chain_id`（该思维链的持久标识）、`revision`（输出修订版本）和 `source_set_id`（本次解析文本的来源版本标识）。父条目元信息仍只来自 Zotero 父条目，附件信息单列用于追溯。

chain_id 是持久且不透明的标识，不由标题、文件名或展示顺序推导；revision 为从 1 开始的正整数，每次发布内容修订递增。同一 revision 发布后不原位改写；这是一份思维链输出的版本，不是 Zotero 条目本身的同步版本。

外部引用必须同时指定文档标识和对象 ID，不能只写“R1”或“第二个分论点”。引用固定到具体 revision，避免文本、层级或连接更新后，原挂载对象悄然变义。

## 7.2 节点与支持链

| 输出对象 | 必需字段 | 含义 |
|---|---|---|
| 节点 | `node_id`、`node_type`、`text`、`original_qualifiers`、`attribution`、`extraction_status`、`text_locations` | 稳定身份、当前层级类型、命题、原文限定、表述归属、提取状态及原文定位 |
| 支持链 | `edge_id`、`from_node_id`、`to_node_id`、`bridge`、`target_part`、`combination`、`attribution`、`extraction_status`、`text_locations` | 稳定身份、支持方向、推理桥、所支持的命题部分、单独或联合使用方式，以及该连接自身的归属、状态和定位 |

`node_type` 只取“核心论点／分论点／论证理由”，`attribution` 和 `extraction_status` 严格遵守 6.1 的分类与组合规则。原文未提供限定时明确留空，不自行补入。联合使用的边在 `combination` 中列出同组 `edge_id`，不能把联合理由误标为各自充分。

稳定节点 ID 采用 `TC-N001` 一类与层级无关的标识，稳定边 ID 采用 `TC-L001` 一类标识。`C1／B1／R1` 仅作为当前展示标签，不作为跨模块引用键。数字不编码章节、父节点或展示顺序。单篇笔记还为每个 TC/EC/RC 对象分配同一空间的全局 index（例如 `ITEMKEY-0001-0001`）。对象 ID 与全局 index 一一对应；重复引用沿用原号。

正式格式固定为：node_id 使用 `TC-N` 后接至少三位十进制数字，edge_id 使用 `TC-L` 后接至少三位十进制数字；同一 chain 内唯一，跨文档必须连同 7.1 的完整身份引用。分论点调为论证理由时，命题含义未变就不因当前角色改变前缀或重新编号。

**稳定性规则**：同一 chain 中，命题含义不变的润色、重排、复用或层级调整保留 node_id；边的端点、方向及论证联系含义不变时保留 edge_id。命题实质改变、拆分或合并，以及边的端点、方向或论证联系实质改变时，分配新 ID，不复用已退役 ID。新旧对象的替代关系如实记录，不把旧挂载自动迁移到新对象；历史 revision 保留。未经身份对齐的新一轮提取不能仅因编号相同就声称对象相同。

“未明确”的候选联系单列，不进入正式支持链表，也没有可供引用的已建立推理桥；两端节点仍可被单独引用。候选内容不因需要跨模块挂载就升级为正式支持关系。

## 7.3 推理桥的精确引用

推理桥归属于支持链：**引用整条连接用 edge_id；专门引用推理桥用同一 edge_id 加字段路径 `bridge`。** 不新增“桥节点”，也不增加论证层级。

外部挂载目标统一包含：文档标识、`target_kind`（节点或边）、`target_id`，以及可选的 `target_field`。例如：

- 指向某项论证理由：节点 `TC-N003`。
- 指向某条分论点至核心论点的连接：边 `TC-L002`。
- 只指向该连接的推理桥：边 `TC-L002` 的 `bridge` 字段。

正式字段统一：target_kind 取 `node／edge`；节点与边整体的 target_field 为 null；专门指向推理桥时，target_kind=edge、target_field=bridge。证据链消费本契约，配套文件为 `evidence-chain-structure-design.md`；关联记录保存在证据链，不使思维链新增科学结果或审查内容。

跨模块引用正式包装为 module=thought、document_ref（7.1 的完整身份）、target_kind、target_id、target_field。本思维链与证据链独立版本化，每个引用固定自己的版本，不要求审查者给所有对象选一个共同 revision。审查链消费本契约，配套文件为 `review-chain-structure-design.md`，判断与建议留在审查链，不回写作者命题。

仅为登记/修改建议指明已有输出容器时，另允许 target_kind=document、target_id=null、target_field 为实际发布的节点/边表名或 null。该文档级引用不是一个命题或支持链，不可当作科学审查目标的替代；不存在的新节点必须先以建议内容描述，不预造 node_id。

节点引用针对命题；边整体引用针对具体推理步骤；bridge 引用针对该步的解释内容。作者确实使用了某一步的行文由 text_locations 追溯，不把这种文本出处自动当作证明推理成立的科学证据。

这里仅提供可寻址目标，不规定外部模块为什么或如何挂载。挂载记录由外部模块保存，思维链不因被挂载而自动新增证据评价、假设或审查裁决；引用方也不直接改写思维链对象。

## 7.4 文本定位字段

节点和边分别持有 `text_locations` 列表，不能只给整篇 Note 一个笼统出处。每项定位记录：`source_set_id`、`attachment_key`、`pdf_role`（MS／SI 等）、`page_pdf`（该附件从 1 起的 PDF 页码）、`block_id`、`section_path` 和 `text_excerpt`（用于辨认的原文短片段）。source_set_id 固定到解析文本版本，避免重新解析后相同 block 编号指向不同内容。

未知页码或章节留空，不生成伪定位；正式输出至少应能通过来源版本、附件及 block ID 定位到解析文本。文本重构涉及多个段落时，列出全部必要位置；节点的出处不能自动替代连接或推理桥的出处。

这些字段只证明表述可回指何处，不表示其中的科学主张已经获得验证。

原文片段另可作为可寻址目标：module=source、target_kind=text_span、source_ref 保存 library_ref、parent_item_key、source_set_id、attachment_key、block_id、span、page_pdf、section_path、text_excerpt，target_field=null。span=null 指整个固定版本块；指定字符区间时，采用从 0 起、左闭右开的 Unicode 码点偏移，针对不可变解析块而非显示规范化文本。该引用没有链节点 target_id，文本身份由 source_ref 给出，不新增第四层节点。作者局限、方法段或回应可直接被审查链引用，无需强造 TC/EC 节点。

# 八、完整展示示例

以下是**人为构造的论证示例**，只演示结构，不对应真实论文，也不表示其中的科学解释已经成立。假定示例中的命题和连接均来自一篇假想论文的明确论述。

## A. 三级论证树

### C1　核心论点〔node_id：TC-N001〕

**在给定工作条件下，界面层 X 对 Zn 负极循环稳定性的改善具有实质作用。**

- **B1　分论点〔node_id：TC-N002〕：界面层 X 降低了持续副反应的倾向。**  
  论证角度：副反应抑制。
  - **R1　论证理由〔node_id：TC-N003〕：界面层 X 降低了可参与副反应的水在反应位点处的有效可达性。**

- **B2　分论点〔node_id：TC-N004〕：界面层 X 缓和了 Zn 沉积的局部集中。**  
  论证角度：沉积分布调节。
  - **R2　论证理由〔node_id：TC-N005〕：界面层 X 减小了不同反应位点之间的局部离子供给差异。**

这部分只展示作者的论证命题，不列实验、数据或文献，不附加审查意见。

## B. 支持关系与推理桥

| 边 ID | 连接（展示标签） | from_node_id → to_node_id | 推理桥（bridge） | 目标部分 | 表述归属 | 提取状态 |
|---|---|---|---|---|---|---|
| TC-L001 | R1 → B1 | TC-N003 → TC-N002 | 作者将反应位点处水的有效可达性降低，作为相关副反应倾向降低的解释。 | 分论点中的副反应抑制。 | 作者明示 | 明确 |
| TC-L002 | B1 → C1 | TC-N002 → TC-N001 | 作者以持续副反应属于循环失稳过程这一联系，将副反应倾向降低作为循环稳定性改善的一条解释路径。 | 核心论点中的稳定性改善路径。 | 作者明示 | 明确 |
| TC-L003 | R2 → B2 | TC-N005 → TC-N004 | 作者将局部离子供给差异减小，作为沉积分布不均减轻的解释。 | 分论点中的局部沉积集中缓和。 | 作者明示 | 明确 |
| TC-L004 | B2 → C1 | TC-N004 → TC-N001 | 作者以局部沉积集中属于循环失稳过程这一联系，将这种集中缓和作为循环稳定性改善的另一条解释路径。 | 核心论点中的另一条稳定性改善路径。 | 作者明示 | 明确 |

例如，外部模块要引用 R1，应指向当前文档版本中的节点 `TC-N003`；要引用 B1 → C1 的推理桥，应指向同一版本中的边 `TC-L002` 的 `bridge` 字段，而不是使用文字“第二条桥”。

本例没有真实 PDF，因此不伪造 library_ref、父条目 key、附件 key、页码、block ID 或原文片段；这里只展示标识与连接方式，不构成可直接交给其他模块使用的正式输出。

本例各节点同样记录“作者明示＋明确”，这是虚构示例的设定，不是真实原文核对结果。若实际论文进一步独立论述了“不可逆消耗降低”等中间命题，应按 5.3 重新归位，不能直接把这些命题藏进上述桥中。

上述连接只说明假想作者怎样组织论证，不评价解释是否正确、联系是否充分或是否存在其他路径。

# 九、思维链的展示目标与完整性

读者应能区分：

1. **中心判断**：论文最想让人接受什么。
2. **论证分工**：不同分论点各自承担什么任务。
3. **具体理由**：每个分论点怎样被展开。
4. **连接方式**：作者怎样将下位命题用于支持上位命题。
5. **文本归属**：哪些内容是作者明示，哪些是根据文本重构。

思维链的结构完整性不以“每层都有内容”为标准，而以以下问题为标准：

> **命题是否明确，层级是否合理，连接是否说明，归属是否清楚，原文限定是否保留。**

这些是对思维链整理质量的要求，不是对论文论证有效性的裁决。

**最终结构：核心论点—分论点—论证理由；支持关系由推理桥解释。证据组织和批评性审查分别留给证据链与审查链。**
