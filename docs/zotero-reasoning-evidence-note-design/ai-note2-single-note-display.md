# 框架分析 - 标题

> 历史单文件展示稿。当前实现不再将三链完整字段交织于一份 note；权威结构、派生索引、分链视图与 Zotero 紧凑视图见 [ai-note2 结构化编码与派生索引设计](structured-encoding-and-indexing-design.md)。下文仅保留为对象与字段的合成示例，不是当前渲染格式。

## 1. 元信息

| 项目        | 展示值／填写位置                                                                                              |
| ----------- | ------------------------------------------------------------------------------------------------------------- |
| 条目信息    | parent item key：[填写]；期刊/DOI：[按父条目填写，缺失留空]                                                   |
| PDF         | 正文附件 key：[填写]；支撑信息附件 key：[填写]；其他附件 key：[填写]；正文/支撑信息判定：[填写依据或“待复核”] |
| AI 分析笔记 | note key：[填写]                                                                                              |
| 文本范围    | PDF 的文本、表格文字及公式文字、图注和脚注，无图片；AI 分析笔记的文本。                                       |

**受控关键词（本稿示意）：**`node_type=核心论点|分论点|论证理由`；`attribution=作者明示|文本重构`；`extraction_status=明确|可重构|未明确`；`combination=单独提供理由|联合使用|未明确`；`research_origin=实验依据|文献依据|未明确`；`primary_aspect=制备|表征|性能|理论|机制`；`finding_status=未发现明确问题|存在条件性疑点|已定位具体问题|当前无法判断`；`check_status=未检查|已检查|当前不可检查|不适用`。正式联系须写明**源 ID → 目标 ID、关系类型、目标部分和出处**。正文提及 ID 不建立正式关系。

| 前缀                                    | 含义                                                        |
| --------------------------------------- | ----------------------------------------------------------- |
| TC-N / TC-L / TC-C                      | 论点 / 支持链 / 候选记录                                    |
| EC-E / EC-P / EC-G / EC-U / EC-M / EC-C | 结果 / 处理关系 / 同源组 / 联合使用组 / 正式用途 / 候选用途 |
| RC-B / RC-K / RC-Q / RC-S / RC-A / RC-D | 背景 / 判准来源 / 审查项 / 覆盖 / 命题评议 / 修改建议       |

其余关键词及字段取值见 [三链属性字典](three-chain-field-catalog.md)。归属与状态配对为“作者明示＋明确”“文本重构＋可重构”或“null＋未明确（候选）”。本稿只展示阅读字段，不代替完整 schema。

## 2. 思维链 - 证据链 - 审查链

本节为虚构展示案例，不是实际论文结论。`SYN-*`、`B001` 等均为示例来源，`p.?` 表示未提供页码。真实笔记须固定解析版本，并按附件、块 ID 和原文片段定位。树最多三级；原文未展开时不补理由，推理桥不增加层级。

### [TC-N001｜ITEMKEY-0001-0001] 核心论点｜给定测试条件下，界面层 X 改善 Zn 负极循环稳定性

- **规范字段：**`node_type=核心论点`；`attribution=作者明示`；`extraction_status=明确`。适用范围：文中给定的体系与测试条件。
- **作者表述定位：**〔SYN-MS / PDF p.? / B001 / “在所述协议下，界面层 X 改善 Zn 负极的循环稳定性。”〕（虚构）

#### [TC-N002｜ITEMKEY-0001-0002] 分论点 A｜界面层 X 降低所测体系中的副反应倾向

- **规范字段：**`node_type=分论点`；`attribution=作者明示`；`extraction_status=明确`。
- **作者表述定位：**〔SYN-MS / PDF p.? / B002 / “作者将 X 与较低的副反应倾向联系起来。”〕（虚构）

**[TC-L001｜ITEMKEY-0001-0003] 通向核心论点的支持链**

- **关系：**`TC-N002 → TC-N001`；`attribution=文本重构`；`extraction_status=可重构`；`combination=未明确`。目标部分：用副反应变化解释循环稳定性改善。组合方式未明确，不等于支持联系未明确。
- **推理桥 `bridge`：**作者把持续副反应与循环失稳联系起来。作者以副反应倾向降低解释所述条件下的稳定性改善。此处记录作者的论证，不判定解释是否成立。推理桥属于支持链，不是第四级节点。
- **关系出处：**〔SYN-MS / PDF p.? / B003 / “作者用累计 H2 比较解释析氢变化，并将其用于循环稳定性讨论。”〕（虚构）
- **用途关联 [EC-M001｜ITEMKEY-0001-0004]：**`subject_ref=EC-E001 → target_ref=TC-L001.bridge`；`usage_role=论证依据`；`use_topic=机制论证`；`attribution=作者明示`；`extraction_status=明确`。目标部分仅为析氢，不扩成全部副反应。用途出处：〔SYN-MS / PDF p.? / B003 / “作者用累计 H2 比较解释析氢变化，并将其用于循环稳定性讨论。”〕（虚构）。这是作者用途，不是支持充分性的结论。
- **审查 [RC-Q001｜ITEMKEY-0001-0006]：**`review_domain=支持关系与推理桥`；`primary_target_ref=TC-L001.bridge`；`issue_origin=审查者提出`。问题：这条桥能否解释所述条件下的循环稳定性变化？判准：解释须对应同一体系和条件，并说明副反应与失稳的联系。依据：[EC-M001｜ITEMKEY-0001-0004] 已限定析氢，但本例未提供这些联系所需的条件。`finding_status=当前无法判断`；`problem_locus=当前无法区分`。不能把现有关联的局部范围误判为“作者声称覆盖全部副反应”；也不据此否定核心论点。

**[EC-E001｜ITEMKEY-0001-0005] 本分论点附近的报告结果｜累计 H2 比较**

- **规范字段：**`research_origin=实验依据`；`primary_aspect=性能`；`result_type=数据处理或统计结果`；`attribution=作者明示`；`extraction_status=明确`。“实验依据”也包含本论文的计算与分析；具体结果类型另记。
- **对象与条件：**实验组 X、对照组、时间窗口及归一化基准：[本例未提供]。对应字段为 null，`field_statuses.status=当前输入未找到`；不等于作者未报告。真实电池记录还须保留适用的载量、电解液量、电流和电压条件及来源。
- **方法与结果：**示例设定作者由气体信号积分、校准得到累计 H2，报告 X 低于对照。原始数值、单位、误差和处理参数：[未提供]。未知数值不填零；不由此推断其他副反应下降。
- **来源：**〔SYN-MS / PDF p.? / B004 / “气体信号经积分及校准后得到累计 H2 量；X 低于对照。”〕（虚构）
- **同源/处理/联合：**`EC-P` 记录已登记结果间的处理方向；`EC-G` 记录共同来源；`EC-U` 记录作者的联合用途。三者不互代。本例未登记原始信号结果，不为建立处理关系补空节点。只有作者确实联合使用多项结果时才建联合组。
- **审查 [RC-Q002｜ITEMKEY-0001-0007]：**`review_domain=来源与一致性`；`consistency_subtype=论文内部一致`；`primary_target_ref=EC-E001`；`issue_origin=审查者提出`。问题：正文与 SI 是否报告同一比较的相反方向？判准：先确认对象、条件、单位、版本和解析结果一致。SI 片段：〔SYN-SI / PDF p.? / B005 / “X 的累计 H2 量高于对照。”〕（虚构）。两个片段方向相反，但条件尚未核对。`finding_status=当前无法判断`；`problem_locus=当前无法区分`。这保留了潜在相反材料，不预先判为论文错误。

##### [TC-N003｜ITEMKEY-0001-0008] 论证理由 A1｜界面层 X 限制反应位置的水可达性

- **规范字段：**`node_type=论证理由`；`attribution=文本重构`；`extraction_status=可重构`；原文限定：[按实际文本填写]。
- **重构依据：**〔SYN-MS / PDF p.? / B006 / “原文关于界面层和水接触的描述。”〕（虚构；真实笔记须给连续原文）
- **[TC-L002｜ITEMKEY-0001-0009] 通向分论点 A：**`TC-N003 → TC-N002`；`attribution=文本重构`；`extraction_status=可重构`；`combination=单独提供理由`。推理桥：作者以水可达性变化解释所讨论副反应的变化。“单独提供理由”不等于充分证明；联合使用时须列出同组支持链。关系出处：[待填；无定位时只能保留草稿，不能作为正式联系]。
- **证据记录 [EC-E002｜ITEMKEY-0001-0010]：**界面表征结果：[对象、条件、方法、报告结果和来源待填]。这是展示占位，未定位结果前不作为正式证据。作者解释若已在 [TC-N003｜ITEMKEY-0001-0008] 中，只引用该论点，不重写一份解释。
- **候选用途 [EC-C001｜ITEMKEY-0001-0011]：**`subject_ref=EC-E002`；`candidate_targets=[TC-L002.bridge]`；`attribution=null`；`extraction_status=未明确`；`decision=pending`。当前未找到作者使用该结果的出处，暂存为草稿线索。先补齐结果及用途来源，再建立新的正式 `EC-M`；候选记录保留。
- **审查 [RC-Q003｜ITEMKEY-0001-0012]：**`review_domain=实证推断`；`primary_target_ref=EC-E002`；`related_target_refs=[TC-L002.bridge]`；`issue_origin=审查者提出`。问题：该表征结果能否作为水可达性的指标？判准：方法的观测量、bulk/surface 范围与目标概念须对应。`finding_status=当前无法判断`。本例没有真实方法或结果，审查项只保留待核问题，不进入正式可靠性裁决。

**[RC-A001｜ITEMKEY-0001-0013] 分论点 A 的限定性评议**

- **评议目标与范围：**`target_ref=TC-N002`；`assessed_scope=所测条件下的副反应表述`。
- **正向依据：**[EC-E001｜ITEMKEY-0001-0005] 的正文报告；相关作者用途 [EC-M001｜ITEMKEY-0001-0004]。仅说明报告和用途已经定位，不自动等同实验结果已独立核实。
- **相反材料：**[RC-Q002｜ITEMKEY-0001-0007] 引用的 SI 片段保留为潜在 `counter_basis`；`conditions_match=尚未核对`。不能只记“有疑点”而丢掉原文，也不能将异条件结果直接当作反证。作者已有回应：[本例未提供，不表示没有回应]。
- **承重缺口：**[RC-Q001｜ITEMKEY-0001-0006] 中副反应到循环稳定性的联系尚未核清。[RC-Q003｜ITEMKEY-0001-0012] 只是待核问题，不当作已定位缺陷；也不冒充对 [TC-N002｜ITEMKEY-0001-0002] 的直接反证。
- **综合结论：**`reliability_statement.conclusion=关键支持仍待核实`（虚构示例）。必要依赖是比较条件及结果到副反应的联系；两者尚未核清。正向报告与潜在相反报告都保留，当前不能选定比较方向，也不能推广到全部副反应。
- **覆盖 [RC-S001｜ITEMKEY-0001-0014]：**`target_refs=[EC-E001]`；`review_domain=来源与一致性`；`criterion_scope=正文与 SI 是否为同条件比较`；`check_status=当前不可检查`；`review_refs=[RC-Q002]`。原因：样品、单位和完整表格未提供。它不代表整条分论点已经审查；其他检查范围分别登记。

#### [TC-N004｜ITEMKEY-0001-0015] 分论点 B｜界面层 X 有助于保持循环过程中的界面状态

- **规范字段：**`node_type=分论点`；`attribution=文本重构`；`extraction_status=可重构`；原文定位：[待填]。本段是展示占位；未补原文前只保留草稿，不作为正式分论点。
- **[TC-L003｜ITEMKEY-0001-0016] 通向核心论点：**`TC-N004 → TC-N001`；`combination=未明确`；推理桥：[根据作者实际文字填写，不能借分论点 A 的桥推断]；来源：[待填]。
- **证据入口：**[EC-E003｜ITEMKEY-0001-0017] 对象、条件、方法、结果及连续原文片段：[待填]。若论文没有把 [EC-E003｜ITEMKEY-0001-0017] 用于此命题，不建立正式 `EC-M`。
- **审查 [RC-Q004｜ITEMKEY-0001-0018]：**`review_domain=结论匹配`；`primary_target_ref=TC-N004`；`issue_origin=审查者提出`。问题：观测时间点能否支持“循环过程中保持”？判准：结论的时间范围应与实际观测相符。`finding_status=当前无法判断`。当前文本不足；旧 AI 笔记只能提供线索，不能代替论文事实。

**[TC-C001｜ITEMKEY-0001-0019] 候选理由 B1｜具体理由待从 PDF 文本确认**

- **状态：**`candidate_kind=命题候选`；`attribution=null`；`extraction_status=未明确`；`decision=pending`。候选不进入正式三级论证树。只有找到独立理由及其原文，才分配新的 `TC-N` 与全局 index，并记录候选的接受结果；原候选号保留。未找到独立理由时，在 [TC-N004｜ITEMKEY-0001-0015] 记 `presentation_status=未进一步展开`，不凑满三级。

**[RC-A002｜ITEMKEY-0001-0020] 核心论点的综合评议**

- **目标：**`target_ref=TC-N001`；`assessed_scope=[所测体系、条件和时间窗]`。
- **承重路径：**[TC-L001｜ITEMKEY-0001-0003] 与 [TC-L003｜ITEMKEY-0001-0016] 各承担什么解释，是否依赖同一批数据：[待核]。
- **有利材料与相反材料：**分别引用对应的 `EC-E` 和 `RC-Q`，说明条件是否相同。同一结果即使在多处出现，也只算一项结果。不按路径数或问题数评分。
- **尚未检查：**逐项记录未取得的图内信息、原始数据和外部文献全文。为每项标明 `check_status=未检查|当前不可检查`；没有审查项不表示检查通过。
- **综合判断：**`reliability_statement.conclusion=当前无法评议`（展示占位）。分论点 A 的必要核对尚未完成，分论点 B 也缺原文。局部疑点不自动否定核心论点，占位路径不算支持。若需要调整命题，只在 `RC-D` 中记录“审查者建议”，不改写作者原论点。

**全局 index：**`ITEMKEY-0001-0001` 对应 `TC-N001`。所有 TC/EC/RC 对象（包括候选）各有唯一号；重复引用沿用原号。序号不代表层级或支持强度，重排不换号；指向推理桥时用支持链的号加 `.bridge`，不另造桥节点。正式引用还须固定对象版本。实际生成时将 `ITEMKEY` 换成父条目 key。
