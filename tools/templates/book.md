## 第一步：判断体裁

首先判断这本书属于哪种体裁，然后按对应的分析框架输出笔记：

- 小说/文学 (fiction)：情节结构、人物、主题、叙事风格、情感共鸣
- 历史 (history)：时代背景、关键事件、人物关系、因果逻辑、作者史观
- 经济/社科 (economics)：核心论点、模型/框架、证据与案例、适用边界、对现实的解释力
- 教材/专著 (academic)：知识体系、核心概念、方法工具、与最新研究的关系

判断体裁后按对应框架组织内容；无论识别为何种体裁，最终都必须且只能输出一个 JSON 代码块（格式见下文），严禁输出散文式读书笔记。

## 必须覆盖的章节（按顺序输出）

## JSON 格式规则（必须遵守）

1. 顶层格式：{"sections": [...]}
2. 允许的 block type：
   - {"type":"heading","level":2|3|4,"text":"..."}
   - {"type":"paragraph","text":"..."}
   - {"type":"bullet_list","items":[{"text":"..."}]}
   - {"type":"table","headers":[...],"rows":[[...]]}
   - {"type":"hr"}
3. 字段名必须使用 text，不要使用 content。
4. 💎 金句摘录 允许在 bullet item 中使用 citations：
   - {"text":"金句内容","citations":[{"location":"章节/页码","content":"上下文"}]}
   - location 只写简短位置（章节/页码），content 写被引用的原文原句
5. 除 💎 金句摘录 外，其他部分不要使用 citations 字段。
6. 必须只输出一个 json 代码块，不要输出代码块外解释文字。
7. 🤔 我的思考 必须包含 4 个四级子标题：同意什么、不同意什么、产生的疑问、对我的启发。
8. 对我的启发 后必须紧跟 bullet_list，至少 3 条，不得为空。
9. 整份输出从头到尾只能是一个 json 代码块，任何散文、标题、总结都只能以 JSON block 形式存在。

## 各章节详细要求

### 📖 一眼判断
- 体裁识别：小说 / 历史 / 经济社科 / 教材专著（加一句判断依据）
- 文本质量：完整度、可读性（正常/有OCR问题/只是章节节选）
- 核心判断：用一句话说这本书值不值得读、适合什么人读

### 🎯 一句话核心
- 用一句话精准概括全书最重要的观点或体验
- 格式：「[作者] 通过 [内容] 说明/展示/论证了 [核心观点]」

### 🗺️ 体裁专项分析
根据识别出的体裁，必须包含以下对应的 4 个四级子标题：

如果是小说/文学：
#### 情节与结构
- 核心冲突是什么？叙事结构（线性/倒叙/多线程）？关键转折点？
#### 人物塑造
- 主要人物的性格弧线、动机、相互关系？谁是最让人难忘的人物？为什么？
#### 主题与象征
- 作者想探讨的核心主题（2-3个）？有哪些重要的象征或意象？
#### 叙事风格与语言
- 叙事视角（第一/第三人称）？语言风格（克制/华丽/讽刺）？有什么独特的写作手法？

如果是历史：
#### 时代背景与核心事件
- 时间跨度、地理范围？作者选取的核心叙事线索是什么？
#### 关键人物与势力
- 决定走向的关键人物（2-4个）？他们的动机与局限？主要势力的博弈？
#### 因果逻辑链
- 作者如何解释这段历史的发展脉络？关键的"为什么"是什么？
#### 史观与叙事偏向
- 作者的史观（结构主义/英雄史观/唯物史观等）？有哪些显著的叙述倾向或可能的盲区？

如果是经济/社科：
#### 核心论点
- 作者想证明什么？主要论证路径（理论推导/实证研究/案例分析）？
#### 关键模型或框架
- 提出了什么模型/框架/工具？如何运作？有哪些核心假设？
#### 证据与案例
- 最有说服力的 2-3 个证据或案例？有哪些案例选择偏差或数据局限？
#### 适用边界与现实解释力
- 这个理论在什么条件下成立？对当前现实的解释力如何？反例是什么？

如果是教材/专著：
#### 知识体系结构
- 这本书构建了什么样的知识框架？各章节的逻辑关系？
#### 核心概念与定义
- 最重要的 5-8 个核心概念（含简洁定义和首次出现位置）
#### 方法与工具
- 介绍了哪些核心方法/技术？各适用于什么场景？
#### 时效性与前沿性
- 内容是否反映最新进展？哪些部分已过时？指向哪些前沿问题？

### 💎 金句摘录
- 选取 5-8 条最有价值的句子或段落（精华而非随机）
- 每条必须标注位置（章节名/页码范围）
- 选择标准：①改变你认知的；②表达极其精准的；③最能代表作者核心观点的

### 🔗 知识连接
- 呼应：哪些书/思想与本书观点相似或互补？（2-3条）
- 对立：哪些书/思想与本书存在分歧？（1-2条，若有）
- 延伸：读完这本书，下一步推荐读什么？为什么？

### 🤔 我的思考（必须包含以下 4 个四级子标题）

#### 同意什么
- 哪些观点/场景/结论让你产生强烈共鸣？为什么？（至少2条）
#### 不同意什么
- 哪些地方你持保留意见？理由是什么？（至少1条，若无则写"暂无明显异议，原因是..."）
#### 产生的疑问
- 读完后你最想追问的 2-3 个问题（不是摘抄，是真实的困惑或好奇）
#### 对我的启发
- 至少 3 条具体可行的启发（此部分不得为空）
  - 对思维方式/认知框架的改变
  - 对实际行动/决策的影响
  - 想进一步探索的方向

### ⭐ 综合评价

以固定表格输出：

| 维度 | 评分(1-5⭐) | 一句话说明 |
|---|:---:|---|
| 内容质量与深度 | ⭐⭐⭐⭐ | ... |
| 叙述/写作质量 | ⭐⭐⭐ | ... |
| 信息密度（干货占比）| ⭐⭐⭐⭐ | ... |
| 观点新颖性 | ⭐⭐⭐ | ... |
| 对我的实用价值 | ⭐⭐⭐⭐⭐ | ... |

- 总体推荐：强烈推荐 / 推荐 / 一般 / 不推荐
- 推荐读法：精读 / 主题章节精读（说明哪几章）/ 泛读 / 作参考工具书
- 适合读者：（描述最适合的读者画像）
- 一句话书评：（如果要你向朋友安利或不安利这本书，你会怎么说）

## 关键硬约束

1. 必须且只能输出一个 json 代码块；严禁输出散文式读书笔记、markdown 正文或任何解释文字。
2. 必须先识别体裁，然后按对应框架输出 🗺️ 体裁专项分析 的 4 个子维度。
3. 金句摘录必须有位置标注，不能只写引用内容没有位置。
4. 对我的启发 不得为空，至少 3 条，若内容不足则写明"本书在XX方面内容有限，但..."。
5. 综合评价表格必须出现，5 个维度缺一不可。
6. 若 PDF 提取质量有问题（OCR错误/只是部分章节），在 📖 一眼判断 中明确说明。

输出要求：
- 使用 markdown 代码块输出 JSON
- 确保 JSON 完整且有效
- 输出精炼完整，避免冗余与空话
- 使用中文撰写，关键术语可用英文标注
- 提取具体数据（数值、单位、条件），重要结论引用原文
- 标注不确定性：无相关内容写“本文未涉及”或“数据不足”
- 即使某节内容较少，也要保留标题结构
- 禁止输出 JSON 代码块以外的任何内容（不要散文式读书笔记、不要开场白或结尾语）
